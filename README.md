# 🐱 紫喵园 (SUATCat)

校园猫咪数字档案与互动平台 —— 发现、记录、分享校园里每一只猫咪的故事。

## ✨ 功能

- **登录引导** — 首次使用引导设置昵称和头像，发布内容前校验身份
- **猫咪档案** — 浏览校园猫咪图鉴，搜索栏和筛选栏固定顶部，按毛色、性别、年龄筛选
- **今日推荐** — 首页随机推荐 2 只猫咪，每次刷新不同
- **发现猫咪** — 拍照上传发现新猫咪，填写基本信息提交审核
- **猫咪详情** — 查看猫咪完整档案：照片轮播、信息、健康状态、中文化年龄标签
- **发现记录** — 为已有猫咪上传新照片，记录相遇时刻
- **便利贴** — 给猫咪贴上文字便签，分享你的观察与心情
- **数据统计** — 在册数量、绝育率、疫苗率、毛色/性别/年龄分布图、当日访问量，支持下拉刷新
- **图片缓存** — 云端图片自动缓存到本地，二次查看秒开，我的页查看缓存大小并一键清除
- **个人中心** — 用户信息、贡献统计、点击头像/昵称可编辑个人信息
- **管理审核** — 管理员审批新猫咪、更新健康状态

## 🛠 技术栈

| 类别 | 技术 |

## 🎨 设计

温暖治愈的校园风格，配色以薄荷绿 `#7EC8A8` 为主色调，搭配奶油米黄 `#FFF8EC` 背景与暖橙 `#F2A65A` 点缀。猫咪卡片采用白底 + 圆角边框 + 柔和阴影，整体统一 16rpx 圆角。

## 🚀 本地开发

1. 克隆项目，用**微信开发者工具**打开根目录
2. 在 `miniprogram/config/index.js` 中填写你的云环境 ID
3. 终端进入 `miniprogram/`，执行 `npm install`
4. 在开发者工具中：**工具 → 构建 npm**
5. 右键 `cloudfunctions/` 下每个云函数目录，选择**上传并部署**

## 📦 云开发

### 数据库集合

| 集合 | 说明 |
|------|------|
| `users` | 用户信息（openid、昵称、头像、角色） |
| `cats` | 猫咪档案（名字、照片、毛色、年龄、性别、健康、状态、位置） |
| `records` | 发现记录 & 便利贴（猫咪关联、照片、内容、发布者） |
| `dailyVisits` | 每日访问量（date、count，首次访问时自动创建） |

### 用户身份校验

`util.js` 中的 `requireProfile()` 方法会检查当前用户是否已设置昵称和头像。以下操作会触发校验：

- 进入「我的」页面
- 提交发现猫咪 / 更新猫咪照片
- 发表便利贴

未设置时自动跳转到登录引导页，设置完成后返回继续操作。

### 图片缓存机制

`cloud://` 格式的云存储图片需先转换为临时 HTTPS 链接才能渲染。`imageCache.js` 在此基础上做了本地持久化缓存：

1. 检查 `imageCacheMap`（Storage 中维护的 `cloud://` → 本地路径 映射表）
2. 缓存命中 → 直接使用本地路径，**无需网络请求**
3. 缓存未命中 → `getTempFileURL` 转换 → `downloadFile` 下载 → `saveFile` 持久化到 `USER_DATA_PATH`
4. 用户可在「我的」页面查看缓存大小并一键清除

### 用户角色

- `student`（默认）— 浏览、上传、记录、写便利贴
- `admin` — 以上全部 + 审核猫咪、更新健康状态

手动在 `users` 集合中将 `role` 字段设为 `"admin"` 即可获得管理权限。

## 📝 猫咪状态流转

```
用户提交 → pending（待审核）
              ↓
     admin approve → approved（已通过，公开可见）
     admin reject  → rejected（已拒绝）
```
